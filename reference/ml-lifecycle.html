Phase 1 • Ingestion & Integrity

Dataset Ingestion & Leak-Free Splitting

Data hygiene is the foundational determinant of model generalization. This phase enforces exact perceptual deduplication, corruption pruning, and strict data leakage prevention between training and evaluation splits.

Workspace Implementation File
src/data/pipeline.py — Implements FireSmokeDataset, get_dataloaders(), DCT-based perceptual hashing, and PyTorch batch collation.

Why This Component Exists

Raw internet/surveillance datasets frequently suffer from repeated frames (burst captures) and corrupt headers. In this repository, the initial exploratory notebook (unstructured_eda_and_feature_engineering.ipynb) only cleaned and augmented the training split. If evaluation splits (validation, test) are left uncleaned, near-duplicate images across train and test artificially inflate accuracy by 8–15% (data leakage).

Invariant Rule: Synthetic oversampling (rotations, blurs, color jitter) is strictly confined to train. Validation and test sets must reflect the authentic natural test distribution.

src/data/pipeline.py — Deduplication & Collation Snippet 
# Perceptual hash (DCT) deduplication with Hamming distance <= 4
def hamming_distance(h1: str, h2: str) -> int:
    return bin(int(h1, 16) ^ int(h2, 16)).count('1')

# Evaluation transforms: 224x224 LANCZOS RGB + ImageNet Normalization
def get_eval_transforms():
    return transforms.Compose([
        transforms.Resize((224, 224), interpolation=InterpolationMode.LANCZOS),
        transforms.ToTensor(),
        transforms.Normalize(mean=[0.485, 0.456, 0.406], std=[0.229, 0.224, 0.225]),
    ])

User-Tunable Hyperparameters

hamming_threshold Integrity
Default: 4
Range: [0, 8]

Bitwise Hamming distance threshold for 64-bit pHash deduplication. Values ≤ 4 aggressively drop near-identical video frames; values ≥ 8 risk dropping distinct fires with similar horizon angles.

batch_size Hardware
Default: 16 (CPU) / 32 (GPU)
Range: [8, 64]

Mini-batch sample count per optimizer step. CPU memory bandwidth constraints make 16 optimal on laptops; remote Colab GPUs can safely scale to 32 or 64.

num_workers Hardware
Default: 0 (CPU) / 2 (Colab)
Range: [0, 4]

Subprocess count for asynchronous data loading. Set to 0 on local machines to avoid shared-memory IPC bottlenecks; set to 2 on Linux/Colab.

Phase 2 • Feature Engineering

Handcrafted Color & Texture Descriptors

Before deploying compute-heavy neural networks, extracting physically interpretable colorimetric and textural descriptors establishes an explainable baseline.

Workspace Implementation File
src/features/extract.py — Implements RGB/HSV color histogram bins, statistical color moments (mean, std, skew), and texture gradient statistics.

Physical Domain Justification

Active flames emit high-luminance Planckian radiation with characteristic spectral signatures in high-red, high-yellow HSV hues. Conversely, smoke plumes manifest as desaturated, diffuse low-saturation distributions with high local texture variance and edge dissipation.

  • 96-Bin Histograms: 16 bins across R, G, B channels and H, S, V channels capture global chromatic shifts.
  • 9 Color Moments: First three central statistical moments (Mean, Standard Deviation, Skewness) per channel capture distribution asymmetry.
  • Texture Descriptors: Sobel gradient variance measures edge sharpness (crisp flame boundaries vs. soft smoke dissipation).
src/features/extract.py — Feature Vector Assembly 
def extract_all_features(image_input) -> np.ndarray:
    # Concatenates:
    # 1. 96-dim Color Histograms (RGB + HSV)
    # 2. 9-dim Color Moments (Mean, Std, Skew per channel)
    # 3. 4-dim Texture Gradient Statistics (Sobel magnitude mean/var)
    hist_feats = extract_color_histogram(image_input, bins_per_channel=16)
    moment_feats = extract_color_moments(image_input)
    texture_feats = extract_texture_features(image_input)
    return np.concatenate([hist_feats, moment_feats, texture_feats]).astype(np.float32)

User-Tunable Hyperparameters

bins_per_channel Resolution
Default: 16
Range: [8, 32]

Histogram quantization bins per color channel. 16 bins balance chromatic resolution (16 × 6 = 96 features) against curse of dimensionality in tree splits.

include_texture Ablation
Default: True
Range: [True, False]

Enables spatial edge filtering. Essential for distinguishing homogeneous sunlight/amber lighting from high-entropy turbulent flame perimeters.

Phase 3 • Tier 1 Baseline

Gradient Boosted Decision Trees (LightGBM)

The non-deep champion candidate: ultra-fast CPU training (< 60s), zero GPU requirement, highly interpretable decision splits, and instant feature importances.

Workspace Implementation File
src/models/train_lightgbm.py — Implements tabular dataset vectorization, loss-penalized gradient boosting, and native booster artifact serialization.

Why We Include a Classical Baseline

In industrial IoT and edge surveillance, deep neural networks often incur unacceptable battery drain and latency. If an engineered feature vector fed into LightGBM can achieve 88% Fire Recall with 2.5ms inference latency, it represents a compelling candidate for low-power edge microcontrollers.

False Negative Penalty Implementation
Configured with class_weight={0: 2.0, 1: 1.0}. Class 0 (Fire) carries double sample weight during histogram binning, forcing leaf splits that prioritize Fire Recall.
src/models/train_lightgbm.py — Configuration Snippet 
model = LGBMClassifier(
    objective="binary",
    n_estimators=200,
    learning_rate=0.05,
    max_depth=6,
    num_leaves=31,
    class_weight={0: 2.0, 1: 1.0},  # Heavy penalty on Fire False Negatives
    random_state=42,
    n_jobs=-1
)

User-Tunable Hyperparameters

class_weight (fire_weight) Safety
Default: {0: 2.0, 1: 1.0}
Range: [1.0, 5.0]

Multiplier for positive fire class gradients. Higher values penalize missed fires heavily, raising Fire Recall at the expense of precision on smoke plumes.

learning_rate Optimization
Default: 0.05
Range: [0.01, 0.2]

Shrinkage factor per boosting iteration. Lower values (0.01) prevent overfitting on small datasets but require larger n_estimators.

num_leaves Capacity
Default: 31
Range: [15, 63]

Main tree complexity controller. In LightGBM (leaf-wise tree growth), num_leaves must be < 2max_depth to avoid deep unregularized splits.

Phase 4 • Tier 2 Deep CNN

ResNet18 Transfer Learning Backbone

The spatial visual pattern anchor: leverages deep ImageNet hierarchical feature representations with selective layer freezing and asymmetric Cross-Entropy loss.

Workspace Implementation File
src/models/train_resnet.py — Implements build_resnet18(), layer freeze masking, weighted CrossEntropy loss, and early-stopping epoch loops.

Freezing Strategy & Architecture Customization

Training 11.2M parameters from scratch on small hazard datasets causes severe overfitting. We freeze the lower convolutional layers (conv1, bn1, layer1), preserving generic low-level Gabor filters (edges, gradients), while fine-tuning layer2, layer3, layer4, and replacing model.fc with:

Linear(512, 512) → Dropout(p=0.3) → Linear(512, 2)
src/models/train_resnet.py — Architecture & Loss 
def build_resnet18(pretrained: bool = True, num_classes: int = 2) -> nn.Module:
    weights = ResNet18_Weights.DEFAULT if pretrained else None
    model = models.resnet18(weights=weights)

    # Freeze low-level feature extractors
    for name, param in model.named_parameters():
        if name.startswith(("conv1", "bn1", "layer1")):
            param.requires_grad = False

    # Custom classification head with dropout regularization
    model.fc = nn.Sequential(nn.Dropout(p=0.3), nn.Linear(512, num_classes))
    return model

# Asymmetric CrossEntropy: w=[2.0, 1.0] penalizes missed fire
criterion = nn.CrossEntropyLoss(weight=torch.tensor([2.0, 1.0]))

User-Tunable Hyperparameters

lr (learning rate) Convergence
Default: 1e-4
Range: [1e-5, 5e-4]

Base learning rate for AdamW. High learning rates (> 1e-3) corrupt pretrained feature extractors in un-frozen layers; 1e-4 provides stable convergence.

fire_weight Safety
Default: 2.0
Range: [1.5, 4.0]

Weight assigned to Class 0 in nn.CrossEntropyLoss. Directly amplifies backpropagation gradients for false negative fire samples.

dropout Regularization
Default: 0.3
Range: [0.1, 0.5]

Probability of zeroing hidden units in the FC head before the 2-class projection. Prevents co-adaptation of features on small batches.

Phase 5 • Tier 3 Vision Transformer

DeiT-Tiny Self-Attention Architecture

Global context via multi-head self-attention: evaluates non-local visual relationships (smoke dispersion plumes vs. focal fire patches) using a lightweight 5.7M parameter transformer.

Workspace Implementation File
src/models/train_vit.py — Implements build_deit_tiny() via timm, patch embedding freeze, and gradient accumulation.

Why Include a Vision Transformer?

Standard CNN convolutions operate over small local receptive fields (3 × 3 or 7 × 7), struggling to connect thin smoke plumes spanning across large scene horizons with distant burning brush. DeiT-Tiny computes pairwise patch attention across all 14 × 14 = 196 patches in layer 1.

Efficiency Optimization: We freeze patch_embed and transformer blocks 0–5, training only blocks 6–11 and the classification head. Gradient accumulation (accum_steps=2) allows achieving an effective batch size of 32 on memory-constrained hardware.

src/models/train_vit.py — Transformer Layer Freezing 
def build_deit_tiny(pretrained: bool = True, num_classes: int = 2) -> nn.Module:
    model = timm.create_model("deit_tiny_patch16_224", pretrained=pretrained, num_classes=num_classes)

    # Freeze patch embedding and first 6 transformer self-attention blocks
    for param in model.patch_embed.parameters():
        param.requires_grad = False
    for block in model.blocks[:6]:
        for param in block.parameters():
            param.requires_grad = False

    return model

User-Tunable Hyperparameters

accum_steps Memory
Default: 2
Range: [1, 4]

Number of mini-batches over which gradients accumulate before optimizer.step(). Simulates batch size 32 with batch size 16 memory footprint.

lr (Transformer) Stability
Default: 5e-5
Range: [2e-5, 1e-4]

Vision Transformers lack inductive biases (translation equivariance) and require lower learning rates than CNNs to avoid attention head divergence.

min_recall Safety Contract
Default: 0.90
Range: [0.85, 0.98]

Mandatory minimum fire recall on validation split. Any threshold candidate yielding recall below this value is rejected regardless of precision.

Phase 7 • Governance & Selection

Latency Profiling & Champion Model Selection

Governing model deployment through objective constraints: disqualify candidates failing safety constraints, benchmark single-sample CPU latency, and serialize runtime metadata.

Workspace Implementation File
src/evaluate/benchmark.py — Implements benchmark_model_cpu() over 100 iterations, select_champion(), and exports champion_config.json.

Champion Governance Decision Tree

The winning model is never chosen based on aggregate accuracy alone. The selection policy executes a strict two-stage filter:

  1. Hard Safety Filter: If Recallfire(test) < 0.90, the candidate is automatically disqualified (unacceptable hazard risk).
  2. Latency Minimization: Among all qualifying architectures meeting Filter 1, select the model with the minimum single-sample CPU inference latency (Tsingle in ms).

τ (ambient threshold) Gate 1
Default: 0.70
Range: [0.60, 0.85]

Minimum maximum softmax confidence required to classify an image as a hazard. If max(P(fire), P(smoke)) < τ, the frame is classified as ambient_frame, suppressing false alarms on everyday background scenes.

θ* (calibrated boundary) Gate 2
From: Phase 6

Calibrated operational threshold loaded from champion_config.json. If Gate 1 passes and P(fire) ≥ θ*, output triggers active Fire alert; else Smoke plume alert.
