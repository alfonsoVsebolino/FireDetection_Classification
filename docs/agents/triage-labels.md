# Triage Labels

Canonical 5-role triage vocabulary configured on GitHub remote:

- `needs-triage`: Newly filed issues awaiting triage.
- `needs-info`: Blocked on clarification or input from reporter.
- `ready-for-agent`: Unblocked, fully specified vertical slice ready for autonomous agent execution.
- `ready-for-human`: Requires manual intervention, credentials, or human decision.
- `wontfix`: Rejected, out of scope, or obsolete.
